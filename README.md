# RMM Threat Intelligence Tracker

Purpose:
Track legitimate Remote Monitoring and Management (RMM) tools that are observed being used by threat actors.

Objectives:
- Identify RMM tools used in malicious campaigns
- Track threat actors abusing RMM software
- Maintain detection opportunities
- Support threat hunting activities

Data Sources:
- BleepingComputer
- The Hacker News
- Huntress
- Sophos
- Microsoft Security
